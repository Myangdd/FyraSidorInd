# 📰 News Site - ASP.NET Core MVC

### Website: https://fyrasidornews.azurewebsites.net/

## 📌 Project Overview
This project is a **news site web application** built with **ASP.NET Core 8 MVC** and hosted on **Azure App Service**. The site includes various categories of news, user authentication, subscriptions, and an admin dashboard.

### 📅 Duration:  
**6-7 weeks** 

## 📜 Features & Requirements

### 🌐 **Pages**
- **Front Page**: Latest news, Editor’s choice, Most popular
- **News Categories**:
  - Local, Sweden, World, Weather, Economy, Sport
- **User Authentication**:
  - Register/Login (with confirmation email)
  - "My Page" (Reset password, view subscriptions, personalized newsletter)
- **Subscription Management**:
  - 'Subscribe Now' links (dummy credit card validation)
- **Admin Pages**:
  - Add & manage articles (upload images)
  - Editor’s choice selection
  - Subscription statistics & user management
- **Privacy Policy** (Cookie consent)

---

## 🌍 **External API Requests**
- **Weather Data**
- **Additional API** (e.g., Business Data, Electricity Prices)

---

## 🏗 **Technical Requirements**
- **ASP.NET Core 8 MVC**
- **SQL Database on Lexicon Server**
- **Services for CRUD operations**
- **View Component **
- **Search Functionality** (news search)
- **Role-based Access Control** (e.g., Editor, Admin)
- **Azure Storage for Images**
- **Search function for archived news**

---

## ☁ **Azure Functions**
- **Send new subscription emails**
- **Personalized newsletters** (weekly)
- **News archiving** (after 30 days)
- **Subscription expiry notifications**
- **Resize images** on upload (Blob trigger)
- **Store historical data** in Azure Tables (weather, business, electricity prices)

### 📊 ** Data Visualization**
- **Subscription statistics** ( ChartJS)
- **Historical data graphs** ( ChartJS)
